# API-model data attribution

The API model was trained using the feature-only MalBehavD-V1 dataset by Pascal Maniriho, Abdun Naser Mahmood and Mohammad Jabed Morshed Chowdhury. Source: [author repository](https://github.com/mpasco/MalbehavD-V1/tree/6aac5027635ac3d2832d323a873fccd7cdd89a5e). Suggested citation: Maniriho, Mahmood and Chowdhury, “API-MalDetect: Automated malware detection framework for windows based on API calls and deep learning techniques,” Journal of Network and Computer Applications, 2023, 103704.

Independent execution reports and family-label mappings used for evaluation came from Raducu, R.; Villagrasa-Labrador, A.; Rodríguez, R. J.; Álvarez, P., **WinMET Dataset**, version 3, 2025, Universidad de Zaragoza. Pinned record: [10.5281/zenodo.16414116](https://zenodo.org/records/16414116). Dataset paper: [MALVADA: A framework for generating datasets of malware execution traces](https://doi.org/10.1016/j.softx.2025.102082).

Raw WinMET archives/reports are not redistributed in this repository or installed with CYBERVEIL. Public repository evidence contains derived scores, hashes, coverage and publisher-label references. Locally retained original JSON inputs are untrusted research data, not executable samples.
